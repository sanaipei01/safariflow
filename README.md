# SafariFlow

SafariFlow is a Matatu Management System.

## Technologies

- Angular (frontend)
- NestJS (backend)
- SQLite with TypeORM (database)

## Structure

- frontend/ : Angular application
- backend/ : NestJS application

## Setup

Frontend:

    cd frontend
    npm install
    npm start

Backend:

    cd backend
    npm install
    npm run start:dev

Copy backend/.env.example to backend/.env before running the backend.
